# DiscordLink

Paper 26.2 plugin: `/discord` shows a clickable Discord invite link.
Set your link in `plugins/DiscordLink/config.yml` (`discord-link`), then `/discord reload`.

Build: JDK 25 + `gradle build` -> `build/libs/DiscordLink-1.0.0.jar`
(or let GitHub Actions build it: Actions tab -> Build plugin -> Artifacts).
